# Onboarding

An iMessage-style onboarding UI that can turn into a phone call. This is the
visual shell: responsive macOS Messages (≥860px) and iOS Messages (narrow, or a
framed iPhone on desktop), incoming/active call screens, light and dark mode.
The conversation is a scripted placeholder.

## Run

```
python3 serve.py
```

Then open http://localhost:5173. The sliders button (bottom left) opens shell
controls: trigger agent messages, typing, a Gmail link card or a call, and force
the layout or theme.
